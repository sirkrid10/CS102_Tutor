## 📅 โครงสร้างการติว (แบ่ง 2 ช่วงเวลา คัดเลือกจาก Grader Problems Latest)

### 1. ช่วงที่ 1 (17:00 – 18:30 น.) : Grader Clinic + 4 เสาหลักครอบคลุม 100% (Survival Kit)
สำหรับน้องที่จำเป็นต้องกลับบ้านก่อน 18:30 น. จะได้ปูพื้นฐานการส่ง Grader ไม่ให้เสียแต้ม พร้อมเห็นแนวคิดครบทุกเสาหลักสำคัญของข้อสอบ:
- **17:00 – 17:15 น. (15 นาที) — เปิดคลาส, แนะนำทีม TA และ Grader Clinic:**
  - แนะนำตัวพี่ TA ประจำแต่ละโซน (ซ้าย / กลาง / ขวา) และกติกาการยกมือขอความช่วยเหลือ
  - ถอดรหัส Error และกับดัก 0 คะแนน: Prompt ขยะ, ลืม `\n`, Trailing space, CE จาก `%lf`, WA จาก Integer division, และ RTE จาก Index เกิน
- **17:15 – 18:30 น. — 4 เสาหลัก (สูตร 10 + 7 นาทีต่อข้อ):**
  1. **Loop + Long Long + Digit Pairing:** `SecretCode001` (รหัสลับ001 - ปี 2568) — จับคู่เลขโดดคำนวณ $\sum(b_i - p_i)^4$ พร้อมดักจำนวนหลักคี่ `INVALID TEXT`
  2. **1D Array + Dynamic Threshold:** `Winners` (เข้ารอบกี่คน - ปี 2567) — อาเรย์ 1 มิติเปรียบเทียบแต้มกับคนสุดท้าย `arr[n-1]`
  3. **2D Array + Traversal:** `SumMatrix` (ผลบวกในเมทริกซ์ - ปี 2567) — ตาราง $4 \times 4$ วิ่งแถวคงที่และวิ่งหลักคงที่
  4. **Strings + Delimiter:** `WordChains` (โซ่คำ - ปี 2568 ล่าสุด) — ตรวจสอบตัวอักษรเชื่อมระหว่างคำคั่นด้วย `_` และนับจำนวนโซ่คำ
  *(เสริม Warm-up Loop Pattern: `LoveLove` ปี 2568 วนพิมพ์แพทเทิร์น Love)*

### 2. ช่วงที่ 2 (18:30 – 20:00 น.) : 4 ข้อเจาะลึกตัดเกรด A/B+ (Deep Dive)
สำหรับน้องที่อยู่ต่อเพื่อลุยโจทย์ระดับตัดเกรด เน้นโจทย์ยาว ตรรกะหลายชั้น และกับดักคณิตศาสตร์/อัลกอริทึม (สูตร 12 + 8 นาทีต่อข้อ):
5. **Frequency Bucket Array & Modulo:** `Enneagram` (นพลักษณ์) — อาเรย์นับความถี่ 1..9 และการหาเศษคนไม่มีกลุ่มด้วย `freq[i] % M`
6. **2D Array Manipulation:** `MaxProduct` (ผลคูณของเวกเตอร์ที่สูงที่สุด - ปี 2568 ล่าสุด) — เมทริกซ์ $M \times M$ หา `max_row_sum * max_col_sum`
7. **Sliding Window:** `MinSumSubArray` (ผลบวกน้อยที่สุดของอาร์เรย์ย่อย) — หน้าต่างเลื่อนขนาด 5 และ **กับดักห้ามตั้ง `min = 0`**
8. **String Scanning & Compare:** `Mushroom` (เห็ดป่า - หมูเด้ง vs หมูดึ๋ง ปี 2567) — สแกนหาอักษร 'W'/'Y' และเปรียบเทียบผลต่าง
*(โบนัสเสริมกลับบ้าน: `SumOfLoves` รับ String มีช่องว่าง, `NoisySequence` สตรีมมิ่งคลื่นสัญญาณ, `numberTriangle` สามเหลี่ยมตัวเลข Modulo)*

## ⚠️ กฎเหล็กที่ต้องจำใน Grader คพ.102 มธ.

1. **ระบุ Header Comment เสมอ:**
   ```c
   /*
   NAME: Firstname Lastname
   SID: 66096xxxxx
   */
   ```
2. **ห้ามพิมพ์ข้อความ Prompt ที่โจทย์ไม่ได้สั่ง** เช่น `printf("Enter number: ");` เพราะ Grader จะมองว่าเป็นคำตอบและให้ 0 คะแนนทันที
3. **ผลลัพธ์สุดท้ายต้องมี `\n` เสมอ** (เคอร์เซอร์ต้องอยู่ที่จุดเริ่มต้นของบรรทัดว่างถัดไป)
4. **ระวังเรื่อง Integer Division** เช่น `75 / 100` จะได้ `0` ทันที ถ้าต้องการคำนวณทศนิยมให้แปลง Type เช่น `75.0 / 100.0`
