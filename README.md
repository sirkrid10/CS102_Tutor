# คลังโจทย์และเฉลยติวสอบ Grader วิชา คพ.102 (CS102)

คลังโจทย์ โครงสร้างโค้ดสำหรับฝึกทำ (Starter Templates) และโค้ดเฉลยภาษา C ฉบับสมบูรณ์ สำหรับการติวนักศึกษาชั้นปีที่ 1 ในรายวิชา **คพ.102 พื้นฐานการแก้ปัญหาและการโปรแกรมคอมพิวเตอร์** ภาควิชาวิทยาการคอมพิวเตอร์ คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยธรรมศาสตร์

## 📅 โครงสร้างการติว (แบ่ง 2 ช่วงเวลา)

การติวใช้กลยุทธ์ **"สูตร 12 + 8 นาทีต่อข้อ"** (ติวเตอร์อธิบาย/Live Code 12 นาที + น้องลงมือพิมพ์ตามและถามพี่ TA 8 นาที):

### 1. ช่วงที่ 1 (17:00 – 18:30 น.) : 4 เสาหลักครอบคลุม 100% (Survival Kit)
สำหรับน้องที่จำเป็นต้องกลับบ้านก่อน 18:30 น. จะได้เห็นแนวคิดครบทุกเสาหลักสำคัญของข้อสอบ:
1. **Loop + Modulo:** `01_BusTicket` (ตั๋วรถเมล์) — การวนแกะบวกเลขทีละหลักจนเหลือเลขหลักเดียว (Digital Root)
2. **1D Array:** `03_MoreThanMean` (มากกว่าค่าเฉลี่ย) — Two-Pass Processing (หา Mean ก่อนแล้ววนนับตัวที่มากกว่า)
3. **2D Array:** `04_SumMatrix` (ผลบวกในเมทริกซ์) — ตาราง $4 \times 4$ วิ่งแถวคงที่และวิ่งหลักคงที่
4. **Strings:** `05_SpecialMessage` (ข้อความพิเศษ) — ตรวจสอบคำคั่นด้วย `_` และเขียนฟังก์ชันตรวจสระ
*(เสริม Pattern Printing: `02_DrawFlag` สลับ `@` และ `#` ด้วย Parity)*

### 2. ช่วงที่ 2 (18:30 – 20:00 น.) : 4 ข้อเจาะลึกตัดเกรด A/B+ (Deep Dive)
สำหรับน้องที่อยู่ต่อเพื่อลุยโจทย์ระดับตัดเกรด เน้นโจทย์ยาว ตรรกะหลายชั้น และกับดักคณิตศาสตร์/อัลกอริทึม:
5. **Simulation & Ceil Math:** `06_ClassCancellation` (การยกเลิกคลาสเรียน) — กับดักปัดเศษขึ้น `(n*k + 99)/100`
6. **2D Array Manipulation:** `07_SwapMatrix` (สลับค่าในเมทริกซ) — In-place Swap และการหาค่าสูงสุดของแต่ละแถว
7. **Frequency Array:** `08_LargestGroup` (ตัวเลขจำนวนมากสุด) — Bucket Array นับความถี่ $1..20$ พร้อมกฎ Tie-Break
8. **Sliding Window:** `09_MaxSumSubArray` (ผลบวกมากที่สุดของอาร์เรย์ย่อย) — ผลบวกต่อเนื่อง 5 ตัว + **ห้ามตั้ง `max=0`**
*(โบนัสเสริมกลับบ้าน: `10_SumOfLoves` การรับ String ที่มีช่องว่างด้วย `scanf("%[^\n]", str)`)*

## ⚠️ กฎเหล็กที่ต้องจำใน Grader คพ.102 มธ.

1. **ระบุ Header Comment เสมอ:**
   ```c
   /*
   NAME: Firstname Lastname
   SID: 66096xxxxx
   */
   ```
2. **ห้ามพิมพ์ข้อความ Prompt ที่โจทย์ไม่ได้สั่ง** เช่น `printf("Enter number: ");` เพราะ Grader จะมองว่าเป็นคำตอบและให้ 0 คะแนนทันที
3. **ผลลัพธ์สุดท้ายต้องมี `\n` เสมอ** (เคอร์เซอร์ต้องอยู่ที่จุดเริ่มต้นของบรรทัดว่างถัดไป)
4. **ระวังเรื่อง Integer Division** เช่น `75 / 100` จะได้ `0` ทันที ถ้าต้องการคำนวณทศนิยมให้แปลง Type เช่น `75.0 / 100.0`
